# DeployX

A portfolio-quality Vercel-inspired deployment dashboard.

## Current features

- Landing page
- Responsive dashboard
- Projects
- Project details
- Deployments
- New Project flow
- Mock deployment API
- Deployment progress UI
- API routes for projects and deployments

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000
